# 우리교회 QT 사이트

교인들이 매일 리딩지저스 읽기 일정과 새벽본문을 따라 QT를 기록하고,
원하면 공동체와 나눌 수 있는 모바일 우선 웹앱.

## 구조

```
src/
  app_head.html   HTML 골격 + CSS + 마크업
  app_js.js       화면 전환, QT 작성/저장, 나눔, 캘린더, 관리자, AI 초안 생성 등 핵심 로직
  bible_js.js     교인이 올린 성경 텍스트 파싱/저장/조회, 본문 참조 해석, 길게 눌러 복사
  badges_js.js    배지·트로피·배지 자랑(나눔) 로직
  books.js        성경 66권 메타데이터(권별 장 수, 분류, 한 줄 소개 — 직접 작성)
  weeks.js        2025-12-29 ~ 2026-12-26 리딩지저스 읽기범위·새벽본문·
                   암송구절 "참조"만 포함 (본문 텍스트는 아래 이유로 제외)
build.py          위 src/*를 dist/qt-site.html 하나로 합치는 스크립트
dist/qt-site.html 최종 산출물 (claude.ai 아티팩트로 게시된 버전과 동일 구조)
```

빌드: `python3 build.py`

## 주요 기능

- **오늘의 QT**: 날짜별 리딩지저스 범위 + 새벽본문, 접기/펼치기(기본 닫힘),
  본문 길게 눌러 복사, 자동/수동 작성한 설명 + 분석 기반 질문(Q1/Q2)
- **QT 설명 작성**: 관리자가 직접 쓰거나, 날짜별 또는 "이번 주 일괄 입력"으로
  붙여넣거나, 관리자 전용 **AI 초안 생성 버튼**(claude.ai의 `sample` 기능 사용,
  게시 페이지 안에서 Claude를 호출해 그 주 새벽본문을 분석한 초안을 만듦)
- **나눔**: 최근 7일 묵상을 최신순으로 모아 보기, 사람별 필터, 5종 공감 반응
  (기도했어요·은혜가돼요·응원해요·함께기뻐요·함께마음써요), 댓글
- **배지·트로피**: 연속기록, 성경 66권 완독, 새벽지기 등 배지와 월간 트로피,
  나눔 화면에 배지 자랑("축하해요")
- **관리자**: 홈 화면 알림(상시 또는 기간 한정), 날짜별/주간 일괄 콘텐츠 편집,
  성경 텍스트 업로드, 별명 기반 관리자 계정 분리
- **초대 링크 복사**, 모바일 키보드와 하단 탭바 겹침 방지, QT 완료 기본 체크 등
  세부 UX 개선 다수

## 중요 — 이 저장소에 포함되지 않은 것

- **성경 본문 전체 텍스트**: 개역개정은 대한성서공회 저작물이라 이 공개
  저장소에는 올리지 않았습니다. 실제 서비스에서는 관리자가 정당하게 보유한
  성경 텍스트 파일을 사이트 내 업로드 기능으로 한 번 올리면, 그 뒤로는
  claude.ai 쪽 저장소(`db` 기능)에만 저장되어 교인들에게 제공됩니다.
- **`weeks.js`의 암송구절 본문**: 같은 이유로 구절 참조(예: `딤후 3:15`)만
  남기고 실제 구절 텍스트는 뺐습니다. 서비스용 원본에는 포함되어 있습니다.
- **원본 핸드북 PDF / 성경 텍스트 파일**: 교회 내부 자료라 포함하지 않았습니다.

## 중요 — 이 코드를 다른 곳에 그대로 올려서 쓸 수 없는 이유

`dist/qt-site.html`은 **claude.ai 아티팩트로 게시되었을 때만** 완전하게
동작합니다. 나눔 게시판, 관리자 콘텐츠·알림 편집, 여럿이 같이 쓰는 성경
본문 저장, 배지 자랑, AI 초안 생성은 모두 claude.ai가 제공하는 런타임
기능(`window.claude` — `db`, `sample`)에 의존합니다.

같은 파일을 GitHub Pages 등 일반 정적 호스팅에 올리면 화면 자체는
뜨지만 `window.claude`가 없어 위 기능들이 전부 조용히 비활성 상태로
시작합니다 (에러 없이 "이 기기에만 저장됩니다" 같은 안내만 보입니다).

즉 이 저장소는 **소스 백업·버전 관리 용도**이고, 교인들에게 실제로
공유하는 링크는 claude.ai 아티팩트 주소를 계속 사용해야 합니다.

## claude.ai 아티팩트로 다시 게시하는 방법

claude.ai에서 **프로젝트에 속하지 않은 일반 새 대화**를 열고(프로젝트
안에서 게시하면 공개 링크 대신 조직 전용 공유로 제한될 수 있습니다),
`dist/qt-site.html`을 가져와 게시해 달라고 요청하면 됩니다.
